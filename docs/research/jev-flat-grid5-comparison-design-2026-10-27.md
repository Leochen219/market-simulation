# Matched flat $5 price-grid comparison

This prospective comparison holds each of the 72 baseline paths' participant, history, current state, side, repeat, and baseline conditioned quantity fixed. It requests one complete price from the 199 dollar values $5 through $995. It changes both the grid and the hierarchical band-then-price interface, together with the necessary prompt wording; it cannot isolate the effect of $5 spacing alone. The 18 development people yield 36 short-three/long-ten contexts and two repeats. The frozen baseline plan and strict replay establish quantities and request provenance; target labels are separate private data and never enter model state.

The original forecast prompt is retained except for the final price-choice sentence, which describes the full grid rather than a selected band. The state retains original history and ledger, replaces the $2.50 grid reference with $5.00, removes band metadata, and supplies the baseline quantity. A single Choice lists all 199 candidates. The top-three raw-probability cutoff is 3%; its draw uses the original seed, person/formal-round coordinate, repeat, and price stage. A valid response with no eligible candidates is client numeric abstention, not a zero price or a model STOP. All 72 planned calls continue after such abstentions.

The predeclared schedule retains baseline path order, with repeat blocks and batches of at most 10, with a 600-second batch bound. The separate ledger caps requests at 72 and cost at 250,000,000 nanodollars; each request reserves 65,536 input tokens at 42 nanodollars per token before dispatch. Transport retains the pinned Jev model and SDK, no retry, no compression or long-context mode, 12,000-byte body limit and existing 10-inflight, 40-RPS, and 50,000 reserved bytes/second caps. Technical errors halt new dispatch, preserve posted attempt evidence and uncertain reservations, and do not trigger automatic resumption. Freeze, run, and replay verify original baseline, source, code, labels, body hashes, candidate order, probabilities, sampling, transport and ledger evidence.

The primary analysis compares old cutoff-3 and new flat-grid prices against raw same-side human order prices on the identical both-success path mask. It pools observations with equal person weight, dividing each person's weight over their matching orders and repeats, then computes one-dimensional Wasserstein distance. Report short-three and long-ten, BUY and SELL separately with people and path counts. Report planned coverage and old empty-support, new client abstention, and technical failures separately. For >=700, [700,800), >250, and > own p, report observed events and planned denominators, hypothetical unreported-price sensitivity bounds (no quote remains an observed client abstention, not a missing actual quote), and corresponding balanced-weight quantities. A common projection of human prices to $5 is a sensitivity analysis. No quote is not a zero price or a human STOP. Aggregate outputs must contain no person IDs or raw state.

The baseline and new wire evidence, labels, states, and individual predictions remain private. Only reviewed aggregate results may be published. Interpretation is descriptive and conditional on fixed baseline quantities; the study is not a causal estimate of grid spacing alone.

Secondary descriptive analysis compares the normalized raw model-score mass on prices >=700 before the cutoff. For the old interface this is the band score multiplied by each saved within-band score conditional on the identical fixed quantity, summed over all four branches. These scores are not established calibrated behavioral probabilities.
